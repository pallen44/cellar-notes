# AGENTS.md

## Project Philosophy

Cellar Notes is a personal wine memory journal.

Prioritize:
- Simplicity
- Beautiful UI
- Mobile-first
- Personal storytelling

Avoid:
- Overengineering
- Premature optimization
- Social features
- AI features
- Anything not in SPEC.md

When unsure, prefer fewer features with better polish.

Always keep v1 finishable in one month.

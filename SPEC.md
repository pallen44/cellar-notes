# Cellar Notes v1 Spec

Cellar Notes is a personal wine memory journal.

## Goal

Build a polished personal web app where I can log wines I drink, upload a label photo, rate the wine, and record the memory around it.

## v1 Features

- Add a wine entry
- Upload a label/bottle photo
- Rate wine from 1-100
- Add winery, wine name, vintage, grape, region, country
- Add price, location, people, food pairing, occasion, and notes
- Browse all wines as cards
- View a wine detail page
- Edit and delete entries
- Search/filter wines
- Mobile-friendly design
- Deployable app

## Not v1

- Social feed
- Friends
- OCR
- AI recommendations
- Public profiles
- Marketplace
- Restaurant/bar discovery
- Complex wine database

## Design vibe

Personal, warm, premium, memory-book feel. More like a beautiful wine scrapbook than a spreadsheet.

## Success criteria

At the end of v1, I should be able to log 10 real bottles and use the app on my phone.
